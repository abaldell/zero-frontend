Documentación del producto

Ejecuta, supervisa y analiza tus pruebas

ZeroApp centraliza la selección de pruebas Playwright, la ejecución en tiempo real y la consulta de evidencias. También permite trabajar con conjuntos y casos de prueba procedentes de SpiraTest.

PlaywrightSpiraTestResultados en tiempo real

Conocer la interfaz

La aplicación está organizada para que puedas pasar de la selección a la ejecución sin perder el contexto.

Barra lateral

Abre o contrae la navegación, accede al Dashboard, entra en los conjuntos de tests y cambia entre tema claro y oscuro.

Ejecutar Tests

Abre el panel lateral desde el que se seleccionan carpetas, archivos y scripts de Playwright.

Vista de ejecución

Muestra el progreso, el resumen y la lista de resultados agrupada por archivo.

Conjunto de tests

Permite consultar conjuntos de SpiraTest, revisar sus estadísticas y lanzar casos automatizados.

ConsejoSi la barra lateral ocupa demasiado espacio, utiliza el control de colapsar. El tema elegido se conserva para próximas visitas en el mismo navegador.

Ejecutar pruebas Playwright

Utiliza este flujo para ejecutar una selección directa de suites y scripts.

  1. Selecciona Ejecutar Tests en la barra lateral.
  2. En el árbol de suites, expande las carpetas y marca una carpeta o un archivo. Puedes seleccionar varios elementos.
  3. Marca los scripts que quieras ejecutar en la lista de scripts disponibles.
  4. Revisa la selección y pulsa Ejecutar selección. Para volver a cargar el contenido, usa Recargar suites.
  5. La aplicación cerrará el panel y abrirá la pantalla de pruebas. Mantén la página abierta para recibir el progreso.
Antes de ejecutarComprueba que el backend esté disponible y que la selección contenga al menos una ruta o script válido. Las carpetas pueden incluir varios archivos, por lo que una selección amplia puede generar una ejecución más larga.

Consultar una ejecución

Progreso

El contador indica las pruebas completadas frente al total. La barra visualiza el avance de las pruebas pasadas y fallidas.

Estado

Durante la ejecución aparece Ejecutando.... Cuando termina, el estado cambia a Finalizado.

Resumen

Al finalizar se muestran las pruebas pasadas, fallidas, omitidas y la duración total en segundos.

Lista de resultados

Los resultados se agrupan por archivo. Selecciona una tarjeta para abrir el detalle de una prueba. El color de la tarjeta ayuda a localizar rápidamente los fallos y los resultados correctos.

Actualización en tiempo realLos cambios llegan mientras la ejecución está activa. Si se pierde la conexión con el servidor, el progreso puede dejar de actualizarse hasta recuperar la conexión.

Analizar el detalle de una prueba

Selecciona una prueba de la lista para revisar su información completa:

Información general

Consulta el nombre, estado, archivo de origen, proyecto, identificador y duración.

Pasos

Expande cada paso para consultar su duración, estado, detalles y los pasos hijos.

Errores

En una prueba fallida se muestran el mensaje, el stack trace y, cuando existe, un fragmento de código relacionado.

Evidencias

Abre el screenshot desde la ventana emergente o accede al trace de Playwright mediante su visor.

Recomendación para investigar fallos

  1. Empieza por el primer paso marcado como fallido.
  2. Expande sus detalles y revisa el mensaje y el stack trace.
  3. Contrasta el error con el screenshot y el trace disponibles.
  4. Utiliza el archivo de origen y el nombre de la prueba para localizar el caso en el proyecto.

Trabajar con SpiraTest

La sección Conjunto de tests permite consultar conjuntos de pruebas y ejecutar los casos que tienen automatización Playwright asociada.

  1. Abre Conjunto de tests desde la barra lateral.
  2. Revisa la tabla de conjuntos: identificador, nombre, estado, release y fecha de actualización.
  3. Selecciona un conjunto para abrir su detalle y consultar sus estadísticas.
  4. En la lista de casos, marca únicamente los casos que tengan correspondencia con una prueba automatizada disponible.
  5. Pulsa Ejecutar pruebas para iniciar la ejecución y consulta sus resultados en la pantalla de ejecución.

Estadísticas del conjunto

El detalle incluye un gráfico con casos pasados, fallidos, bloqueados, en precaución, no ejecutados y no aplicables. La barra de la tabla representa visualmente pasados, fallidos, no ejecutados y bloqueados.

ImportanteLa selección solo está disponible para casos con automatización Playwright asociada. Los resultados editados en la pantalla no se publican actualmente de forma automática en SpiraTest.

Estados y leyenda

Los nombres pueden variar según el origen del resultado. Esta es la interpretación habitual:

Requisitos y limitaciones conocidas

  • El backend debe estar disponible en la URL configurada para la aplicación.
  • Los screenshots, vídeos y traces dependen de que el backend sirva correctamente los archivos de evidencia.
  • El visor de traces utiliza actualmente http://localhost:9323/trace/index.html; debe ser accesible desde el navegador.
  • La integración usa actualmente el proyecto SpiraTest con identificador 1.
  • El Dashboard existe como pantalla inicial, pero todavía no muestra información funcional completa.
  • La barra de progreso de la ejecución contabiliza principalmente estados pasados y fallidos; otros estados pueden no incrementar el porcentaje.
  • La actualización de resultados depende de los eventos en tiempo real del servidor.
